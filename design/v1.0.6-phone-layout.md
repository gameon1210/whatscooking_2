# 1.0.6: Android layout and dish browsing

The tab bar reserves the bottom safe area while retaining its existing control height. Shared form screens and modal sheets now use the Expo-compatible keyboard controller, with keyboard-aware scrolling and sticky actions; the web implementation follows visual viewport changes. “Our family” replaces the home headcount wording. Dish browsing now continues from ranked suggestions into a paged full catalogue, including from Today.

`react-native-keyboard-controller` 1.21.9 is new native code. Android uses resize mode; the preview build increments its version code so it can update an existing installation. A new Android APK is required. Existing data structures and on-device records are unchanged.
