# What's Cooking 2.0

A family food-decision app: it decides the next meal from your family's history and rules,
hands it to the cook on WhatsApp, and closes the loop on leftovers, tiffins and groceries.

- `app/` — the Expo (React Native) app for Android, iPhone and web. Start with [app/README.md](app/README.md).
- `docs/cook.html` — the free Cook page, served by GitHub Pages.
- The `.docx` files are the product specs; the current one is *What's Cooking 2.0 — Functional Specification (FSD)*.
